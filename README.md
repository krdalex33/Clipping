# 🎬 Бот для нарезки YouTube на вертикальные клипы 9:16

Телеграм-бот: присылаешь ссылку на видео с YouTube — получаешь готовые
вертикальные клипы (Reels/Shorts/TikTok) с субтитрами и лёгкой уникализацией.

- Транскрипция и выбор моментов — через **Groq API** (быстро, без GPU).
- Монтаж — чистый **ffmpeg** (зеркало, зум, цветокор, размытый фон, субтитры).
- Хостинг — **bothost.ru** (деплой из GitHub, сборка по Dockerfile).

Эта инструкция рассчитана на человека **без опыта программирования**. Делай по шагам.

---

## Что понадобится (3 бесплатные вещи)

1. **Токен Telegram-бота** — из @BotFather.
2. **Ключ Groq API** — с console.groq.com (бесплатный тариф есть).
3. **Аккаунт на GitHub** — чтобы залить туда код.
4. (Желательно) **cookies YouTube** — чтобы YouTube не блокировал скачивание.

---

## Шаг 1. Токен Telegram-бота

1. Открой в Telegram чат с **@BotFather**.
2. Отправь команду `/newbot`.
3. Придумай имя и username бота (username должен заканчиваться на `bot`).
4. BotFather пришлёт строку вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxx` — это и есть **BOT_TOKEN**. Сохрани.

---

## Шаг 2. Ключ Groq API

1. Зайди на **https://console.groq.com** и войди (можно через Google).
2. Слева выбери **API Keys** → **Create API Key**.
3. Скопируй ключ вида `gsk_...` — это **GROQ_API_KEY**. Сохрани (показывается один раз).

---

## Шаг 3. Cookies YouTube (важно для стабильности)

YouTube часто требует «подтвердите, что вы не робот». Чтобы этого избежать, боту
дают cookies залогиненного аккаунта.

### Как выгрузить cookies.txt

Самый простой способ — расширение браузера:

1. Установи расширение **«Get cookies.txt LOCALLY»** (есть для Chrome и Firefox).
2. Зайди на **youtube.com** и убедись, что ты залогинен.
3. Нажми на иконку расширения → **Export** → сохранится файл `cookies.txt`.

> Совет: заведи для бота отдельный Google-аккаунт (не основной) — cookies с него
> и используй. Так безопаснее.

### Как превратить cookies.txt в строку YT_COOKIES_B64

Нужно закодировать файл в base64 (одна длинная строка):

- **macOS** (Терминал):
  ```bash
  base64 -i cookies.txt | pbcopy
  ```
  Строка скопируется в буфер обмена — вставляй её в переменную `YT_COOKIES_B64`.

- **Windows** (PowerShell):
  ```powershell
  [Convert]::ToBase64String([IO.File]::ReadAllBytes("cookies.txt")) | Set-Clipboard
  ```

- **Linux**:
  ```bash
  base64 -w0 cookies.txt
  ```

> Cookies живут недолго (дни–недели). Если бот начал писать «YouTube требует
> авторизацию, обнови cookies» — просто повтори этот шаг и обнови переменную.

## Шаг 4. Залить код на GitHub

1. Создай аккаунт на **https://github.com** (если нет).
2. Нажми **New repository** → назови, например, `clipping-bot` → **Private** →
   **Create repository**.
3. Загрузи файлы проекта. Проще всего через сайт:
   на странице репозитория **Add file → Upload files**, перетащи ВСЕ файлы и папки
   проекта (включая папки `bot/` и `assets/`), внизу нажми **Commit changes**.

> ⚠️ Файл `.env` с секретами загружать НЕ нужно — он в `.gitignore`. Секреты
> введёшь прямо в панели Bothost (Шаг 5).

Должны попасть в репозиторий:
```
bot/                     ← весь код бота
assets/fonts/            ← шрифт Montserrat-Bold.ttf (нужен для субтитров!)
selftest.py
requirements.txt
Dockerfile
.env.example
.gitignore
README.md
```

## Шаг 5. Настроить Bothost

1. Зайди на **https://bothost.ru** и создай проект **из GitHub-репозитория**.
2. Тип сборки — **Dockerfile** (в репозитории он уже есть, ничего писать не надо).
3. Ресурсы: **~2 ГБ ОЗУ, 15 ГБ диска** — этого достаточно.
4. В разделе **переменные окружения (Environment / ENV)** добавь:

   | Переменная       | Обязательна | Значение                                  |
   |------------------|-------------|-------------------------------------------|
   | `BOT_TOKEN`      | да          | токен из Шага 1                           |
   | `GROQ_API_KEY`   | да          | ключ из Шага 2                            |
   | `YT_COOKIES_B64` | желательно  | base64-строка из Шага 3                   |
   | `YT_PROXY`       | нет         | прокси, если YouTube блокирует IP         |
   | `ADMIN_ID`       | нет         | твой Telegram ID (бот напишет при старте) |
   | `CLIPS_COUNT`    | нет         | сколько клипов на видео (1–5, по умолч. 3)|

5. Запусти деплой. В логах должно появиться: `Старт polling.`
6. Напиши боту в Telegram `/start` и пришли ссылку на YouTube.

> Свой Telegram ID можно узнать у бота **@userinfobot**.

## Как это работает

1. Присылаешь ссылку → бот отвечает «Принял, в очереди».
2. Скачивает видео (до 720p, не длиннее 90 минут).
3. Извлекает аудио и распознаёт речь (Groq Whisper). Язык определяется
   автоматически: русская речь → русские субтитры, английская → английские.
   **Ничего не переводится.**
4. Нейросеть (Groq LLM) выбирает 3–5 самых сильных фрагментов по 30–60 секунд.
5. Каждый фрагмент превращается в вертикальный клип 1080×1920: зеркало + лёгкий
   зум + цветокор + размытый фон + субтитры + небольшое ускорение (уникализация).
6. Клипы приходят в чат по мере готовности, с подписью-причиной выбора.

## Проверка без Telegram (для смелых)

В проекте есть `selftest.py` — прогоняет весь монтаж локально и печатает отчёт.
Нужен установленный `ffmpeg` и (для реальной транскрипции) `GROQ_API_KEY`.

```bash
pip install httpx
export GROQ_API_KEY=gsk_...
python selftest.py
```

Скрипт сам создаст тестовое видео, распознает речь, выберет моменты и соберёт
клипы, а в конце напишет `ИТОГ: PASS ✅`.

## Типовые ошибки и что делать

| Сообщение бота / лог                                   | Что значит и что делать                                                                 |
|--------------------------------------------------------|-----------------------------------------------------------------------------------------|
| `YouTube требует авторизацию, обнови cookies`          | Устарели cookies. Повтори Шаг 3 и обнови `YT_COOKIES_B64`, перезапусти бота.             |
| `Видео слишком длинное … Максимум — 90 минут`          | Пришли ролик короче 90 минут.                                                           |
| `Видео недоступно (приватное, удалено…)`               | Ссылка на приватное/удалённое/заблокированное видео. Возьми другое.                     |
| `Groq отклонил ключ (401/403)`                         | Неверный `GROQ_API_KEY`. Проверь, что скопировал целиком.                               |
| `Groq превысил лимит запросов (429)`                   | Слишком часто. Подожди минуту. При больших объёмах — платный тариф Groq.                |
| `Транскрипт пустой — не распозналась речь`             | В видео нет речи (только музыка/тишина). Возьми видео с разговором.                     |
| `YouTube временно ограничил запросы (429)`             | Задай `YT_PROXY` или подожди 10–15 минут.                                               |
| В логах при старте `не задана переменная окружения …`  | Не заполнена обязательная переменная. Добавь её в ENV на Bothost.                       |
| В логах при старте `не найден ffmpeg`                  | Сломан Dockerfile. Убедись, что тип сборки — Dockerfile и файл не изменён.              |

## Частые вопросы

**Клип пришёл «документом», а не видео.** Значит, он получился больше 50 МБ
(лимит Telegram для ботов). Бот заранее пытается сжать, но иногда так надёжнее
доставить. Файл рабочий, просто скачай его.

**Можно ли переводить субтитры?** Нет, по задумке язык субтитров = язык речи.

**Сколько стоит?** Хостинг — по тарифу Bothost. Groq — есть бесплатный лимит;
для потока видео может понадобиться платный тариф.

**Не переводит на другой язык / не меняет голос.** Так и задумано: инструмент
режет и оформляет, не редактирует смысл.
